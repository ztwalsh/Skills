# Logo project data

No database. A logo project is a folder of plain files. `logo.json` and the round files are the
source of truth; `viewer/sync.mjs` checks them and writes `data.js` (what the viewer loads) and
the readable history.

## Folder layout

```
logo/
  index.html            the viewer (from the skill; do not hand-edit)
  DESIGN.md             the viewer's design guide (customizable)
  viewer-tokens.css     the viewer's tokens (customizable)
  viewer/               logo.css, logo.js, sync.mjs, outline.mjs, geo.mjs, vendor/, VERSION (from the skill)
  data.js               generated by sync.mjs, never hand-edited
  logo.json             the project: name, colours, wordmark, rounds, picks, log, outcome
  wordmark/             the supplied wordmark artwork, kept as received; fonts/ holds downloaded font files
  rounds/
    round-1.mjs         the marks of round 1
    round-2.mjs
  HISTORY.md            generated; only when the repo has no brain/ folder
```

## IDs

- A mark's ID is `r<round>-<number>`, three digits: `r1-017`, `r4-029`.
- Numbering restarts at 001 in each round.
- IDs are permanent. Never renumber, never reuse a number, never delete a mark. A weak mark may
  be replaced while a round is being drawn; once the user has seen the round, it is fixed.
- Rounds are only added, never replaced.

## `logo.json`

```jsonc
{
  "schema": 1,
  "name": "movethink",
  "created": "2026-11-13",
  "status": "open",                       // open | decided | archived
  "area": "brand",                        // area in brain/decisions/index.md
  "colors": { "ink": "#131312", "paper": "#FAF8F5" },   // the brand's two colours; marks are one colour

  "wordmark": {
    "parts": ["move", "think"],           // one or two words. With two, the mark can sit between them.
    "active": "supplied",                 // the wordmark in use: "supplied" or a font id
    "supplied": {                         // the user's own artwork, as outlines; null if none was given
      "parts": [{ "d": "M100.25 268V188.2…" }, { "d": "M653.85 268C…" }],   // one path per word, in the artwork's own coordinates, never redrawn
      "baseline": 268,                    // y of the baseline
      "xTop": 186,                        // y of the top of the x-height
      "ascTop": 161,                      // y of the top of the ascenders (cap height if all caps)
      "joinShift": -169.88                // two words only: x translation of the second word so the name reads as one word
    },
    "fonts": [                            // typefaces to explore, from Google Fonts
      { "id": "geist-500", "family": "Geist", "weight": 500, "tracking": -0.04, "transform": "lowercase", "italic": false,
        "outline": null }                 // filled in when the font is outlined (reference/type.md); same shape as "supplied"
    ]
  },

  "brief": { "quote": "…the user's ask, word for word…", "date": "2026-11-13" },

  "rounds": [                             // metadata only; the marks are in rounds/round-N.mjs
    { "n": 1, "date": "2026-11-13", "brief": { "quote": "…", "by": "user" }, "from": [], "summary": "100 marks. Typography unchanged." },
    { "n": 2, "date": "2026-11-13", "brief": { "quote": "…", "by": "user" }, "from": ["r1-017", "r1-020"], "summary": "…" }
  ],

  "picks": { "r1-017": "chosen", "r3-002": "dropped", "r4-029": "final" },   // only marks with a status; the rest are open

  "log": [
    { "date": "2026-11-13", "type": "brief", "by": "user", "marks": [], "quote": "…", "note": "" }
  ],

  "outcome": null                         // when decided, see below
}
```

### `outcome`

```jsonc
{
  "mark": "r4-029",
  "date": "2026-11-13",
  "headline": "Scattered thoughts, coming together.",       // the idea in one line
  "idea": "Small dots in even rows. Nothing is added…",      // two or three sentences
  "reads": [                                                  // optional: how the mark reads, left to right or step by step
    { "title": "Scattered", "text": "Separate dots, each one small." }
  ],
  "minSize": 32,                                              // smallest size for the full mark, in px
  "smallCut": {                                               // optional: a simpler drawing for small sizes
    "name": "Small cut, six columns", "svg": "<circle…/>", "maxSize": 32,
    "note": "The finest dots are dropped so the idea survives at 16."
  }
}
```

## Round files

`rounds/round-N.mjs` is a JavaScript module so marks can be drawn with helpers and loops. It
exports one object:

```js
import { bar, dot, ring } from '../viewer/geo.mjs'

export default {
  families: [
    {
      name: 'The slash',
      note: 'The "/" of the name as one or two shapes, cut and split.',   // one line
      parents: ['r1-017'],          // optional: every mark in the family grew from these
      marks: [
        { n: 11, name: 'One slash', svg: bar(0, 0, 120, 16) },
        { n: 12, name: 'Broken slash', svg: '<path d="…"/>', parents: ['r1-020'] },   // a mark's own parents override the family's
      ],
    },
  ],
}
```

A mark:

| Field | Meaning |
|---|---|
| `n` | Its number in the round, 1 to 999 |
| `name` | Two or three words |
| `svg` | SVG markup drawn in a 140 × 140 box, centre (70, 70). One colour: `currentColor` fills, no hex colours. Use `§` wherever an id is needed (masks, clips); the viewer swaps it for a unique token per instance. |
| `parents` | IDs of the marks it grew from (rounds 2 and later) |
| `fixed` | `true`: draw exactly as given, no auto-fit. For supplied or finished artwork. |
| `noFit` | `true`: centre it but do not scale it |
| `s`, `dx`, `dy` | Extra scale after the fit, and optical nudges in box units |

Unless `fixed`, the viewer measures each mark and centres it in the box, scaled down to fit
inside 128 units. So draw at any convenient size; only proportions matter.

## The log

Same rules as the brainstorm skill. The log is append-only; entries are added, never edited.

1. Write the entry in the same turn the decision is made.
2. `quote` is the user's words exactly, typos included. Never tidied, shortened or merged.
3. `note` is the agent's reading and is shown as such. Agent entries carry no `quote`.
4. A pick with no reason gets an empty quote and `"note": "No reason given."` after asking once.
5. The agent's shortlist is a `recommend` entry. The user's picks are `chosen` entries.
6. Keep `picks` in step with the log: `chosen`, `dropped`, `final`.

| Type | By | When |
|---|---|---|
| `brief` | user | The ask that started the project |
| `recommend` | agent | The agent's shortlist after a round |
| `chosen` | user | Marks picked to keep or grow |
| `dropped` | user | Marks or a whole direction ruled out |
| `feedback` | user | What starts the next round; also stored as that round's `brief` |
| `refined` | agent | A mark was adjusted after being picked; `note` says how |
| `final` | user | The winner |
| `note` | either | A rule or constraint that came out of the work, including the choice of typeface |

## `data.js`

Generated. The viewer reads only `window.LOGO`: everything in `logo.json`, plus `modified`,
`generated`, `history` (path of the generated history), and `rounds` with the marks merged in:

```js
window.LOGO = {
  /* …logo.json… */
  rounds: [
    { n: 1, date, brief, from, summary,
      families: [{ name, note, marks: [{ n, id: 'r1-001', name, svg, parents: [], fixed?, noFit?, s?, dx?, dy? }] }] }
  ]
}
```
