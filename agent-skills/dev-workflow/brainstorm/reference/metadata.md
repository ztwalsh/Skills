# Playground metadata

There is no database. Each brainstorm keeps one file, `playground/<slug>/brainstorm.json`, and
that file is the source of truth for the shell, the lineage and the history. `sync.mjs` reads
every `brainstorm.json` and writes `playground/data.js` (what the shell loads) and the readable
history.

## Folder layout

```
playground/
  index.html            shell (from the skill, do not hand-edit)
  DESIGN.md             the shell's design guide (customizable)
  tokens.css            the shell's tokens (customizable)
  shell/                shell.css, shell.js, sync.mjs, VERSION (from the skill)
  data.js               generated by sync.mjs, never hand-edited
  <slug>/
    brainstorm.json
    HISTORY.md          generated; only when the repo has no brain/ folder
    pass-1/
      idea-001-<kebab-name>/
        thumb.png       square illustration, 1440 × 1440
        ...             the idea itself, when the host stack lets it live here
    pass-2/
      ...
```

## IDs

- An idea's ID is `p<pass>-<number>`, three digits: `p1-001`, `p2-017`.
- Numbering restarts at 001 in each pass.
- IDs are permanent. Never renumber, never reuse a number, never delete an idea's entry. A
  dropped idea keeps its entry with `status: "dropped"`.
- Passes are only added, never replaced.

## `brainstorm.json`

```jsonc
{
  "schema": 1,
  "slug": "analytics-page",              // folder name, kebab-case
  "title": "Analytics page",
  "description": "Ways to show a month of entries at a glance.",   // one line, for the index
  "area": "insights",                    // an area from brain/decisions/index.md, or "product-wide"
  "status": "open",                      // open | decided | archived
  "created": "2026-11-15",
  "modified": "2026-11-16",              // set by sync.mjs from the latest log entry
  "brief": {
    "quote": "I want to explore a new analytics page",   // the user's words, verbatim
    "date": "2026-11-15"
  },
  "passes": [
    {
      "n": 1,
      "date": "2026-11-15",
      "brief": { "quote": "I want to explore a new analytics page", "by": "user" },
      "from": [],                        // idea IDs this pass grew from; empty for pass 1
      "summary": "Five directions, from a dense table to a single headline number.",   // agent's words
      "ideas": [
        {
          "id": "p1-001",
          "name": "Dense table",
          "bet": "Every entry visible at once beats any summary.",   // one line
          "dir": "pass-1/idea-001-dense-table",    // relative to the brainstorm folder
          "thumb": "pass-1/idea-001-dense-table/thumb.png",   // omit until it exists
          "source": "src/playground/analytics/DenseTable.tsx",  // path from the repo root
          "url": "http://localhost:5173/playground/analytics/dense-table",  // omit if no live view
          "parents": [],                 // idea IDs this one grew from
          "status": "open",              // open | chosen | dropped | final
          "eval": { "score": 7, "note": "Clear, but heavy on a phone." }   // optional
        }
      ]
    }
  ],
  "log": [
    {
      "date": "2026-11-15",
      "type": "brief",                   // brief | recommend | chosen | dropped | feedback | refined | final | note
      "by": "user",                      // user | agent
      "ideas": [],                       // idea IDs involved
      "quote": "I want to explore a new analytics page",   // verbatim; users only
      "note": ""                         // the agent's own words, always labelled as the agent's
    }
  ],
  "outcome": null                        // when decided: { "idea": "p3-004", "date": "...", "summary": "..." }
}
```

## Rules for the log

The log is the history. It is append-only: add entries, never edit or delete one.

1. **Write at the moment of the decision,** in the same turn the user makes it. Not at the end
   of the session, and never reconstructed later from memory.
2. **`quote` is verbatim.** Copy the user's words exactly, typos included. Do not tidy, shorten
   or merge quotes. If the user said nothing quotable, leave `quote` empty.
3. **`note` is the agent's reading** and is shown as such. Never put an interpretation in `quote`.
4. **A missing reason is recorded as missing.** When the user picks ideas without saying why,
   ask once for a line. If they skip it, write the entry with an empty quote and
   `"note": "No reason given."` Never invent a reason.
5. **Recommendations are separate from picks.** The agent's shortlist is a `recommend` entry
   (`by: "agent"`). The user's picks are `chosen` entries (`by: "user"`). The record should show
   where the user agreed and where they went another way.
6. **One entry per event.** Choosing three ideas for one reason is one `chosen` entry listing
   three IDs. Choosing them for different reasons is three entries.
7. **Keep idea status in step with the log.** A `chosen` entry sets those ideas to `chosen`;
   `dropped` sets `dropped`; `final` sets one idea to `final`, sets the brainstorm's `status` to
   `decided` and fills `outcome`.

## Entry types

| Type | By | When |
|---|---|---|
| `brief` | user | The ask that started the brainstorm |
| `recommend` | agent | The agent's shortlist after a pass, with why in `note` |
| `chosen` | user | The user picks ideas to keep or grow |
| `dropped` | user | The user rules ideas or a whole direction out |
| `feedback` | user | The feedback that starts the next pass; also stored as that pass's `brief` |
| `refined` | agent | An idea was edited in place after feedback; `note` says what changed |
| `final` | user | The user picks the winner |
| `note` | either | Anything else worth keeping: a constraint, a rule that came out of the work |

## `data.js`

Generated. The shell reads only this:

```js
window.PLAYGROUND = {
  schema: 1,
  generated: "2026-11-16T15:04:05.000Z",
  historyDir: "brain/decisions/brainstorms",   // or null when histories live in the playground
  brainstorms: [ /* every brainstorm.json, unchanged, newest modified first */ ]
}
```

Paths in `thumb` and `dir` are relative to the brainstorm's folder, so the shell resolves a
thumbnail as `<slug>/<thumb>` from `playground/index.html`.
