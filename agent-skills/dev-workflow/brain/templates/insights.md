# Insights

What we have learned from users and from building. Newest first. Add to the top; never rewrite
an old entry. If one turns out to be wrong, add a new entry that says so and points back.

Each entry:

```
## YYYY-MM-DD · The insight in one line
**Source:** user said | builder noticed | data showed | agent noticed
**Evidence:** the quote, the number, or what was seen. Quotes are word for word.
**So what:** what this should change. Leave empty if not yet known.
**Status:** open | acted on (link to the decision) | promoted to a principle | no longer true
```
